# Proyecto y Entregables del Semestre – Arquitectura Empresarial

## Descripción general
Este repositorio reúne todos los entregables desarrollados a lo largo del semestre para la asignatura de Arquitectura Empresarial de la Universidad de La Sabana.

El trabajo se construyó de manera progresiva, abordando diferentes dimensiones del análisis y diseño arquitectónico de un cliente real, desde el modelado de procesos y datos hasta la infraestructura, seguridad, normatividad y gobierno de arquitectura. Cada carpeta corresponde a un taller o entrega específica del curso y conserva la estructura definida para su desarrollo.

## Objetivo del repositorio
Centralizar en un solo espacio todos los artefactos, documentos, modelos, análisis y entregables desarrollados durante el semestre, con el fin de:
- evidenciar el avance del proyecto de forma organizada;
- mantener trazabilidad del trabajo realizado;
- consolidar los talleres en un único repositorio;
- facilitar la revisión académica del proceso completo.
